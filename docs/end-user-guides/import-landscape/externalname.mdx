# External Name

Crossplane uses [`external-name` annotation](https://docs.crossplane.io/latest/guides/import-existing-resources/) to indicate and link external ressources. 

As not all BTP ressources return a unique GUID as an identifier, the following table summarizes how they are handled instead.
